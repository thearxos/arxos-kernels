# arxos-kernels

Prebuilt ARXOS kernels, published as GitHub Releases. The Control Center Kernels tab (via
`arxos-kernel`) lists, installs, and rolls back between them.

- **linux-arxos** — default: BORE + ThinLTO, pinned.
- **linux-arxos-zen** — rolling max-performance: BORE + Full LTO.

Each version is a Release; assets are `<kernel>-<ver>-x86_64.pkg.tar.zst` (plus `-headers-`).
